# منصة الداتا بيز | DBMS Learning Platform

منصة تعليمية إلكترونية تفاعلية واحترافية متقدمة متخصصة في دراسة وتطبيق مقرر **نظم إدارة قواعد البيانات (Database Management Systems - DBMS)**، كود المقرر **CS436 / CS339**، والمخصصة للاستعداد المتكامل للامتحان النصفي (Midterm Examination) عبر تغطية شاملة للمحاضرات من الأولى إلى التاسعة (Lectures 1–9 Inclusive).

---

## 📌 المعلومات الأكاديمية ونطاق المنصة

* **المقرر:** Database Management Systems (DBMS).
* **كود المقرر:** CS436 / CS339.
* **الهوية:** منصة تعليمية مستقلة ذات هوية أكاديمية قياسية.
* **النطاق الأكاديمي المعتمد:** المحاضرات من 1 إلى 9 (Lectures 1–9 Inclusive) للاستعداد للامتحان النصفي (Midterm Exam).
* **الملف الأكاديمي الأساسي والمرجعي:** `DBMS_Midterm_Summary_Lectures_1-9.md`.
* **العلامة البرمجية المائية:** `ASH`.

---

## 🚀 المعمارية التقنية والوظائف البرمجية

### 1. الواجهة الأمامية (Frontend)
* **HTML5 Semantic:** بنية دلالية مدعومة بعناصر إمكانية الوصول والتنقل السهل وواجهة مستخدم متجاوبة بالكامل لجميع مقاسات الشاشات (الهواتف المحمولة، الأجهزة اللوحية، والشاشات الكبيرة).
* **قائمة جانبية متكيفة للهواتف:** مزودة بزر Hamburger Menu، وخلفية معتمة (Dark Backdrop Overlay)، وزر إغلاق سريع، ودعم مفتاح `Escape`، وإغلاق تلقائي عند اختيار أي قسم لمنع التمرير الأفقي.
* **زر العودة للرئيسية («منصة الداتا بيز»):** مدمج في رأس الصفحة للعودة الفورية إلى لوحة التحكم (Dashboard) دون إعادة تحميل الصفحة ودون فقدان التقدم الدراسي.
* **دعم RTL و LTR:** واجهة عربية أصيلة مع عزل المعادلات والرموز والجداول والاعتماديات الوظيفية والجبر العلائقي داخل حاويات LTR لمنع تشوه المعادلات والأسهم.
* **Vanilla JavaScript ES6+:** كود معياري منظم مقسم إلى وحدات (ES Modules) مستقلة وخفيفة دون أي أطر عمل خارجية ثقيلة.
* **KaTeX Math Engine:** عرض فوري للمعادلات الرياضية، رموز الجبر العلائقي ($\sigma, \pi, \rho, \times, \cup, \cap, -, \bowtie, ⟕, ⟖, ⟗$) وإغلاق الصفات ($X^+$).
* **LocalStorage:** حفظ تقدم الطالب، الموضوعات المكتملة، سجل الامتحانات، أعلى نتيجة، والملاحظات الشخصية محلياً.

### 2. الواجهة الخلفية ومساعد الذكاء الاصطناعي (Backend & AI RAG)
* **PHP 8.2 Backend:** معمارية خفيفة وقوية لتأمين الاتصال بنماذج Google Gemini API وعدم تسريب المفاتيح للمتصفح.
* **محرك استرجاع المعلومات الأكاديمي (RAG Engine):** يقوم بفهرسة وتجزئة ملف الملخص الأكاديمي المعتمد `DBMS_Midterm_Summary_Lectures_1-9.md` إلى 64 قسماً ومطابقتها دلالياً ولغوياً مع استفسارات الطلاب لتقديم إجابات أكاديمية دقيقة وموثقة بأرقام المحاضرات والسلايدات.
* **معالجة الأخطاء الذكية:** استجابة سلسة عند غياب مفتاح API أو حدوث انقطاع في الشبكة دون تعطيل باقي أقسام المنصة، مع تشفير المفاتيح في سجلات الأخطاء.

### 3. الجاهزية للنشر المتعدد (Multi-Environment Deployment)
* **XAMPP (Windows):** تعمل محلياً بمرونة كاملة عبر Apache و PHP.
* **حاويات Docker و Render:** مزودة بـ `Dockerfile` و `docker-entrypoint.sh` يدعم الربط الديناميكي للمنافذ عبر `$PORT` الخاص بمنصة Render.

## 🧪 المختبرات التفاعلية الأربعة (Interactive Simulators Lab)

1. **حاسبة إغلاق الصفات والمفاتيح المرشحة (Attribute Closure & Candidate Keys):**
   * حساب خوارزمية $X^+$ خطوة بخطوة مع إظهار الاعتمادية المطبقة في كل خطوة.
   * استخراج كافة المفاتيح المرشحة الأصغرية بطريقة الاستدلال الأكاديمي وتصنيف السمات إلى $L, R, B, N$.
   * فاحص صيغة بويس-كود المعيارية (BCNF Checker) والتحقق مما إذا كان كل محدد مفتاحاً فائقاً.
2. **محاكي مراحل التطبيع (Normalization Visualizer):**
   * محاكاة بصرية لمراحل التحويل: UNF $\to$ 1NF $\to$ 2NF $\to$ 3NF $\to$ BCNF.
   * يحتوي على مسألة DreamHome ومسألة درجات الطلاب STUDENT_RECORD مع تبيان الشوائب، والاعتماديات، والمفاتيح.
3. **محاكي التحويل ذو الخطوات السبع (7-Step ER Mapper):**
   * استعراض تفاعلي لخطوات تحويل مخططات ER إلى مخططات علائقية، وتوضيح قواعد وضع المفاتيح الأساسية والأجنبية.
4. **مختبر الجبر العلائقي (Relational Algebra Playground):**
   * محرك جبر علائقي ينفذ عمليات الاختيار ($\sigma$) والإسقاط ($\pi$) مع حذف التكرار، والضرب الديكارتي ($\times$)، والربط الطبيعي ($\bowtie$).
   * فحص صارم لشرط التوافقية للاتحاد (Union Compatibility) مع إظهار رسائل أكاديمية توضيحية.

## ⏱️ محاكي الامتحان النصفي (Timed Mock Exam Simulator)

* نموذج تدريبي رسمي من **50 درجة**:
  - السؤال الأول (10 درجات): 10 عبارات صواب أو خطأ مع تحديد التصحيح الأكاديمي.
  - السؤال الثاني (15 درجة): 10 أسئلة مفاهيم واختيار من متعدد.
  - السؤال الثالث (12 درجة): مسألة تطبيع STUDENT_RECORD وحساب الإغلاق والمفاتيح.
  - السؤال الرابع (13 درجة): أسئلة التصميم EER والتحويل والجبر العلائقي.
* مؤقت تنازلي حي (60 دقيقة / 20 دقيقة).
* وضع التركيز الامتحاني (Exam Lock Mode).
* تسليم تلقائي عند نفاد الوقت، وحساب دقيق للدرجات مع تقرير تشخيصي يحدد الموضوعات المتقنة وتلك التي تتطلب مراجعة.
